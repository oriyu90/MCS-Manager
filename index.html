01 / OPERATE

運用に必要なものを、
ひとつの画面へ。

ターミナルを何枚も開かなくても、サーバーの現在地が分かる。毎日の操作と、異常に気づくための情報を近くに置きました。

01

複数サーバーを登録

PROFILES

Paper、Spigot、Purpur、vanilla JARと独自のstart.shに対応。起動・停止・再起動をサーバーごとに扱えます。

02

プレイヤーと権限を管理

PLAYERS & ACCESS

参加者、OP、BAN、ホワイトリストを確認。ホワイトリストはメンバー追加だけでなく、機能自体の有効・無効も切り替えられます。

03

Webから同じ状況を見る

BUILT-IN WEB

選択したサーバーの状態、設定、ホワイトリスト、コンソールを一つのタブで表示。LAN内や安全に構成した外部接続から利用できます。

04

登録解除はワールドを消さない

SAFE BY DEFAULT

一覧から削除しても解除されるのはMCS Managerへの登録だけ。Minecraftサーバーフォルダやワールドデータは残ります。

02 / OBSERVE

数字の変化を、
問題になる前に。

CPU、Javaプロセスのメモリ、接続遅延、TPS、MSPTを監視。メモリ増加傾向やラグの兆候を、確定診断と混同しない形で知らせます。

サーバー負荷 / 直近10分

一時的な山と継続的な悪化を見分けるための推移。

ヘルスチェック

  • TPS / MSPT正常
  • 接続遅延24 ms
  • メモリ傾向安定
  • 応答状態監視中

03 / COMPATIBILITY

世代に合ったJavaで、
迷わず起動。

バージョンを検出して要件を確認

サーバーのMinecraftバージョンに応じて必要なJava世代を案内します。独自の起動スクリプトがある場合は、その指定を優先します。

1.20.0–1.20.4Java 17以上✓
1.20.5–1.21.xJava 21以上✓
26.xJava 25以上✓

04 / WEB ACCESS

外から見るなら、
安全も一緒に。

Web管理画面とJSON REST APIを内蔵。

管理ポートを無認証でインターネットへ公開しないでください。長い管理パスワードに加え、HTTPS対応リバースプロキシ、VPN、アクセス元制限のいずれかを併用してください。
